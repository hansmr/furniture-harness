# furniture-harness

Harness de Claude Code para diseño de muebles en madera y PVC.

## Cómo se usa
1. Abre esta carpeta con Claude Code.
2. Ejecuta `/brief-de-diseno` para empezar un mueble nuevo.
3. Sigue las fases de `CLAUDE.md`: brief → modelo FreeCAD → revisión → planos, BOM y guía de montaje.

Datos de materiales en `catalogos/` (Homecenter Colombia, 2026-11-22). Configuración en `config/proyecto.yaml`.
